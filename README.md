# ⚡ Pedro Henrique — Página Pessoal de Links

Página pessoal de links de alta performance, desenvolvida com estética **Dark Cyberpunk** e experiência refinada para desenvolvedores de software.

Criada sob medida para ser utilizada na bio do Instagram (`@henriique.dev`), LinkedIn e compartilhamento profissional.

---

## 🚀 Tecnologias

- **React 19** + **TypeScript**
- **Tailwind CSS v4** + **@tailwindcss/vite**
- **Vite** (Build ultra-rápido)
- **Lucide Icons** + SVGs personalizados

---

## 🎨 Recursos de Design

- **Avatar com Anéis Neon**: Foto original com concentric glowing ring e indicador de status verde ("Disponível para projetos").
- **Fundo Tecnológico**: Grid cibernético sutil com esferas de luz azuis/ciano e vinheta radial suave.
- **Botões Dinâmicos**: Efeito de iluminação que varre o card no hover, cantos arredondados (`rounded-2xl`) e backdrop blur de vidro escuro (`bg-slate-900/70`).
- **Mobile First**: Layout perfeitamente adaptado para celulares (tamanho de toque ideal) e telas desktop.

## 🌐 Como Publicar na Vercel (Gratuito)

1. Suba este repositório para o seu GitHub (ex: `pedro-henrique-silva-dev/links`).
2. Acesse [vercel.com](https://vercel.com) e faça login com seu GitHub.
3. Clique em **"Add New..."** → **"Project"**.
4. Selecione o repositório `links`.
5. Clique em **"Deploy"** (a Vercel detecta Vite automaticamente).
6. Em ~30 segundos sua página estará online com HTTPS gratuito!

### Situação do domínio `henrique.dev`:
- `henrique.dev` já se encontra **registrado e em uso** por outro titular (apontando para Cloudflare).
- **Sugestão oficial:** `henriique.dev` (com dois 'i's, exatamente igual ao seu Instagram `@henriique.dev` e seu e-mail `henriique.dev7@gmail.com`), que está disponível para registro!

### Para conectar qualquer domínio na Vercel:
1. No painel do seu projeto na Vercel, acesse: **Settings** → **Domains**.
2. Digite seu domínio (ex: `henriique.dev`).
3. Adicione os registros DNS (tipo `A` ou `CNAME`) indicados pela Vercel no seu registrador (ex: Registro.br, Porkbun, Cloudflare ou Namecheap).
